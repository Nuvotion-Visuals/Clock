# Nuvotion Clock

https://clock.nuvotion.live

12 hour clock with date and weather.

![image](https://github.com/user-attachments/assets/0ad8418a-f195-4c31-867b-139ad04313a5)

## Features

- 12 hour clock
- Ticking second hand
- Continuous minute and hour hand
- Weekday / Month / Day display, e.g. "Friday, March 21st"
- Current temperature / daily high / daily low
- Current weather icon
- 4 satellite clocks, see below

## Satellite Clocks
Turn on satellite clocks by pressing "V" on the keyboard.

- next 12 hour weather
- next 12 hour temperature
- 12 months of the year
- 28-31 days of the month

![image](https://github.com/user-attachments/assets/d695fab3-a1f9-4306-b9dc-11c6fb176ea6)

## Bonus Features

- Press "C" to change the second hand from red to white
- Press "B" to enable anti-burn-in mode, which causes the content to slowly move around the screen
